# 시공검토 앱 (굴착·시공 단계 검토) — 휴대폰 설치 방법

이 폴더는 휴대폰 홈 화면에 설치해 앱처럼 쓰는 웹앱(PWA)입니다. 한 번 열면 인터넷이 없어도 동작합니다.
(글꼴만 처음 연결 때 받아 오며, 오프라인에서는 기본 글꼴로 보입니다.)

## 0. Claude 없이 쓰는 법 (누구나)
이 앱은 Claude 계정이 없어도 일반 브라우저(크롬·사파리·삼성 인터넷)에서 그대로 동작합니다.
- **파일 하나로 쓰기**: `시공검토_단일파일.html`을 카카오톡·메일로 보내고 안드로이드에서 '크롬으로 열기'. (아이폰은 파일로는 실행이 안 되므로 아래 주소 방식 사용)
- **주소로 쓰기 (권장 · 아이폰 포함)**: 아래 1번처럼 이 폴더를 무료 호스팅에 올려 https 주소를 만들고 그 주소를 카톡으로 공유 → 각자 '홈 화면에 추가'.
- Claude 안에서만 되는 기능: 사진·PDF 도면 'AI 판독'만 빠지고(선 추출·DXF 판독은 그대로), 나머지(2D·3D·시공 재생·내역서·견적·CAD/PDF 출력)는 모두 됩니다.

## 1. 인터넷 주소 만들기 (한 번만)
앱은 https 주소에서 열어야 설치됩니다. 가장 쉬운 방법:

- **Netlify Drop**: PC에서 https://app.netlify.com/drop 에 이 폴더(압축 푼 `app` 폴더)를 끌어다 놓기 → 주소가 바로 생김
- 휴대폰만 있을 때: **tiiny.host** 등 HTML 올리기 사이트에 `시공검토_단일파일.html` 하나만 올려도 주소가 생깁니다
- 또는 **GitHub Pages**: 저장소에 폴더 내용을 올리고 Settings → Pages 켜기

## 2. 휴대폰에 설치
- **안드로이드 (Chrome)**: 주소 열기 → 오른쪽 위 "📲 앱 설치" 버튼, 또는 메뉴(⋮) → "앱 설치 / 홈 화면에 추가"
- **아이폰 (Safari)**: 주소 열기 → 공유(□↑) → "홈 화면에 추가"

## 3. 사용
- 아래 메뉴: 2D 단면 · 3D · 시공 재생 · 입력 · 검토표
- 3D: 한 손가락 회전, 두 손가락 확대·이동
- 가로 화면으로 돌리면 그림이 더 크게 보입니다. "크게 보기"는 전체 화면입니다.

## 파일
- `index.html` 앱 본체 · `lib/` 3D 라이브러리(three.js r128) · `sw.js` 오프라인 캐시 · `manifest.webmanifest` 앱 정보 · `icons/` 아이콘

※ 표시되는 기준(산안규칙 별표11, KDS, 주차장법 시행규칙 등)은 현행 법령으로 확인하십시오.
